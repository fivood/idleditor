# 弹窗画框 PNG 规范（9-slice / CSS border-image）

把手绘像素画框 PNG 放到这个目录，文件名严格匹配下列对照表即可被 `ScenePanel` 自动接管。文件不存在时面板退回纯色兜底，不影响游戏运行。

## 文件对照

| variant | 用途 | 文件名 | 兜底色 |
|---------|------|--------|--------|
| paper   | 通用纸张面板 | `panel-paper.png`   | `#2a1810` |
| inbox   | 投稿池（木质收件托盘） | `panel-inbox.png`   | `#4a2f18` |
| belt    | 编辑流水线（铁质传送带） | `panel-belt.png`    | `#2a1810` |
| journal | 出版日志 / 档案（羊皮日记） | `panel-journal.png` | `#3a2412` |
| scroll  | 猫详情 / 秘密事项（展开卷轴） | `panel-scroll.png`  | `#3a2418` |
| notice  | 征稿 / 公告板（软木板） | `panel-notice.png`  | `#8b6b3e` |

## 画布规格

- **尺寸**：建议 `48×48 px`（最常用）。也可以是 `32×32`（更紧凑）或 `64×64`（更精细），改完到 `src/components/scene/ScenePanel.tsx` 把对应 variant 的 `slice` 改成新尺寸的 1/3 即可。
- **网格**：将画布等分 3×3，每格 16×16（按 48×48 算）：

  ```
  ┌─────┬─────────┬─────┐
  │ TL  │ T-edge  │ TR  │   ← 顶部
  ├─────┼─────────┼─────┤
  │ L   │ CENTER  │ R   │   ← 中部
  │edge │ (可平铺) │edge │
  ├─────┼─────────┼─────┤
  │ BL  │ B-edge  │ BR  │   ← 底部
  └─────┴─────────┴─────┘
   16px    16px    16px
  ```

  - **四角**（TL/TR/BL/BR）：固定 16×16，画清晰的拐角装饰
  - **四边**（T/B 水平、L/R 垂直）：16×16，必须做到「左右像素 / 上下像素无缝可平铺」
  - **中央 CENTER**：16×16，必须能在任意方向平铺无缝（纸纹 / 木纹 / 软木颗粒），不要画到对称中心物件
- **配色**：保持暗调色板（参考兜底色）；画框边缘要有可识别的轮廓线，避免和场景背景糊在一起。

## 平铺策略（border-image-repeat）

代码里所有 variant 当前都是 `repeat`（等距平铺）。如果你想换：
- `round` — 整数倍缩放，保证每格完整不切边（推荐给装饰元素强的画框）
- `space` — 平铺但格之间留缝隙（一般不用）
- `repeat` — 平铺到边界可能被切（最像素友好）
- `stretch` — **不要用**，会拉伸糊化

需要切换：改 `ScenePanel.tsx` 里对应 variant 的 `repeat` 字段。

## 验证清单

画完后导出 PNG（无 alpha 透明可选，但建议保留 alpha 让阴影更自然）放到本目录。开浏览器看：

1. 弹窗顶部 + 底部边框上下连贯，看不出"接缝"
2. 中央纹理在长方形拉伸下不重复出可见图案（或重复但有意为之）
3. 缩放浏览器窗口至 720px 宽（窄屏）→ 画框依然锐利不糊
4. 跨 DPR（普通屏 + Retina）外观一致

不通过的话首选检查中央格的"可平铺性"——左右像素列、上下像素行要严格对齐。

# 标题栏画框 PNG 规范（可选，9-slice）

如果你想让弹窗的标题栏也走手绘像素艺术——比如做"刻字铜牌"、"羊皮日记的丝带"、"软木板的红色横条"——把对应 PNG 放到本目录，文件名严格匹配下表即可被 `ScenePanel` 接管。**完全可选**：不画就退回当前的"标题色文字 + 底分割线"样式。

## 文件对照

| variant | 用途 | 文件名 |
|---------|------|--------|
| paper   | 通用纸张标题条 | `titlebar-paper.png`   |
| inbox   | 木质托盘的铁牌 | `titlebar-inbox.png`   |
| belt    | 流水线的金属铭牌 | `titlebar-belt.png`    |
| journal | 日记本的丝带书签 | `titlebar-journal.png` |
| scroll  | 卷轴顶部的吊穗 | `titlebar-scroll.png`  |
| notice  | 公告板的红色横栏 | `titlebar-notice.png`  |

## 画布规格

- **尺寸**：`16×16 px`（与按钮同规格，slice = 4）
- 也可以画成 `24×16` / `16×24` 等矩形（条状形态更自然）。改 `ScenePanel.tsx` 里对应 variant 的 `slice` 值即可适配。
- **网格**（按 16×16 / slice=4 计）：

  ```
  ┌──┬────┬──┐
  │TL│ T  │TR│   ← 顶 4×4
  ├──┼────┼──┤
  │L │CTR │R │   ← 中 4×4（水平方向被拉伸成整条标题栏的长度）
  ├──┼────┼──┤
  │BL│ B  │BR│   ← 底 4×4（接面板边框，可以画一根分割线像素）
  └──┴────┴──┘
   4    4   4
  ```

  - **TL / TR**：左右两端的固定装饰（铆钉、丝带末端、印章）
  - **T / B 边**：横向平铺；T 通常是高光带、B 通常是底部分割线
  - **L / R 边**：纵向 4 像素（如果你只想要一行标题，L/R 几乎不可见）
  - **CTR 中央**：标题栏的主体填充——平铺的木纹/羊皮/红条等

## 配合标题文字

代码层面标题文字始终用 CSS 字体渲染叠加在画框之上：
- 文字色取 variant 自带的 `titleColor`（在 `ScenePanel.tsx` 里改）
- 文字加 `truncate` 防溢出，所以标题画框两端最好画对称——画师无法预测文字长度

## 不画也可以

如果你只画了 panel 没画 titlebar，标题栏会自动用纯色 + 底部 1px 分割线，跟现在的视觉一致。**先 panel 后 titlebar 是合理的迭代顺序**——panel 决定主基调，titlebar 是锦上添花。

# 按钮画框 PNG 规范（同样 9-slice）

按钮也走 9-slice，但更紧凑——画布更小，slice 更窄。文件名严格匹配下列对照表即被 `PixelTextButton` 自动接管，缺失时降级为 CSS 立体凸起。

## 文件对照

| variant | 用途 | 文件名 | 兜底主色 |
|---------|------|--------|---------|
| default | 灰色硬质塑料按钮（OK / 取消 / 常规） | `button-default.png` | `#a8a8a8` |
| primary | 铜色（主 CTA：审稿 / 提交 / 确认出版） | `button-primary.png` | `#b8763b` |
| danger  | 暗红（破坏性操作：退稿 / 撤销） | `button-danger.png`  | `#a04030` |

## 画布规格

- **尺寸**：`16×16 px`
- **网格**：3×3 网格，每格 `4×4 px`（slice = 4）

  ```
  ┌──┬────┬──┐
  │TL│ T  │TR│   ← 顶 4×4
  ├──┼────┼──┤
  │L │CTR │R │   ← 中 4×4（可平铺）
  ├──┼────┼──┤
  │BL│ B  │BR│   ← 底 4×4
  └──┴────┴──┘
   4    4   4
  ```

  - **四角**（TL/TR/BL/BR）：4×4，画拐角高光/阴影像素
  - **四边**（T 顶 / B 底 / L 左 / R 右）：4×4，必须可平铺（按钮被横向拉伸时复制此格）
  - **中央 CTR**：4×4，按钮主体色（被填满整个内部区域，平铺）

## 8-bit 立体凸起的实现建议（仅参考）

如果想保留经典 NES/SFC 风格的"凸起感"——

- **TL**：左上一像素亮白色（高光），其余主色
- **TR**：右上一像素深色（阴影边缘）
- **BL**：左下一像素深色
- **BR**：右下两像素更深（投影）
- **T-edge / L-edge**：靠近内边的一行/列用高光色
- **B-edge / R-edge**：靠近内边的一行/列用阴影色
- **CTR**：纯主色（或细微噪点纹理）
- 整张图最外圈用 1px 黑边封装（NES 风格的硬轮廓）

> 这样平铺时：左边和顶边总有高光带、右边和底边总有阴影带——按钮立即"凸起"。

## hover / active 状态

代码自动处理：
- **hover** → 整图 `filter: brightness(1.1)`（提亮 10%）
- **active 按下** → 整图向右下 1px 偏移

你不需要画 hover/pressed 状态 PNG（除非想要更精细的反馈，后续可扩展）。

# 通用提醒

1. 所有 PNG **必须像素整数对齐**（不要在编辑器里用浮点缩放）
2. 导出时**关闭抗锯齿**（PNG 直接是离散像素值）
3. 颜色限制在 8-bit 范围内即可（不需要严格 8-bit 调色板，但少色更协调）
4. 用 `image-rendering: pixelated` 渲染（代码已设置），无须你手动放大资源
5. 兜底色已经能让游戏正常玩，所以**画一张接管一张**——不必一次画全
