# 弹窗画框 PNG 规范（9-slice / CSS border-image）

把手绘像素画框 PNG 放到这个目录，文件名严格匹配下列对照表即可被 `ScenePanel` 自动接管。文件不存在时面板退回纯色兜底，不影响游戏运行。

## 文件对照

| variant | 用途 | 文件名 | 兜底色 |
|---------|------|--------|--------|
| paper   | 通用纸张面板 | `panel-paper.png`   | `#2a1810` |
| inbox   | 投稿池（木质收件托盘） | `panel-inbox.png`   | `#4a2f18` |
| belt    | 编辑流水线（铁质传送带） | `panel-belt.png`    | `#2a1810` |
| journal | 出版日志 / 档案（羊皮日记） | `panel-journal.png` | `#3a2412` |
| scroll  | 猫详情 / 秘密事项（展开卷轴） | `panel-scroll.png`  | `#3a2418` |
| notice  | 征稿 / 公告板（软木板） | `panel-notice.png`  | `#8b6b3e` |

## 画布规格

- **尺寸**：建议 `48×48 px`（最常用）。也可以是 `32×32`（更紧凑）或 `64×64`（更精细），改完到 `src/components/scene/ScenePanel.tsx` 把对应 variant 的 `slice` 改成新尺寸的 1/3 即可。
- **网格**：将画布等分 3×3，每格 16×16（按 48×48 算）：

  ```
  ┌─────┬─────────┬─────┐
  │ TL  │ T-edge  │ TR  │   ← 顶部
  ├─────┼─────────┼─────┤
  │ L   │ CENTER  │ R   │   ← 中部
  │edge │ (可平铺) │edge │
  ├─────┼─────────┼─────┤
  │ BL  │ B-edge  │ BR  │   ← 底部
  └─────┴─────────┴─────┘
   16px    16px    16px
  ```

  - **四角**（TL/TR/BL/BR）：固定 16×16，画清晰的拐角装饰
  - **四边**（T/B 水平、L/R 垂直）：16×16，必须做到「左右像素 / 上下像素无缝可平铺」
  - **中央 CENTER**：16×16，必须能在任意方向平铺无缝（纸纹 / 木纹 / 软木颗粒），不要画到对称中心物件
- **配色**：保持暗调色板（参考兜底色）；画框边缘要有可识别的轮廓线，避免和场景背景糊在一起。

## 平铺策略（border-image-repeat）

代码里所有 variant 当前都是 `repeat`（等距平铺）。如果你想换：
- `round` — 整数倍缩放，保证每格完整不切边（推荐给装饰元素强的画框）
- `space` — 平铺但格之间留缝隙（一般不用）
- `repeat` — 平铺到边界可能被切（最像素友好）
- `stretch` — **不要用**，会拉伸糊化

需要切换：改 `ScenePanel.tsx` 里对应 variant 的 `repeat` 字段。

## 验证清单

画完后导出 PNG（无 alpha 透明可选，但建议保留 alpha 让阴影更自然）放到本目录。开浏览器看：

1. 弹窗顶部 + 底部边框上下连贯，看不出"接缝"
2. 中央纹理在长方形拉伸下不重复出可见图案（或重复但有意为之）
3. 缩放浏览器窗口至 720px 宽（窄屏）→ 画框依然锐利不糊
4. 跨 DPR（普通屏 + Retina）外观一致

不通过的话首选检查中央格的"可平铺性"——左右像素列、上下像素行要严格对齐。

## 参考工具

- Aseprite：自带「Pattern / Tileable」预览，最适合做 9-slice
- Photoshop：用 `Filter > Other > Offset` 偏移半张图来手动检查接缝
- 任何像素编辑器都行，只要能锁画布到 48×48
