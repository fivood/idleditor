# 永夜出版社 · 代码绘制场景

更新：2026-09-29（v2.10）。

## 当前实现

六个房间按 **480×270** 的布局网格构图，以 **960×540** 原生像素栅格化（`UNIT = 2`：图形、纹理、光照抖动、雨雪在原生分辨率绘制，肖像用 `p.fine()` 逐像素绘制），使用固定色板及六档明暗色阶（第六档只在雷暴闪光时出现）。场景不依赖 PNG。

- 主编室（`src/art/editorRoom.ts`，沿用最初位图版氛围）：砖墙、三联窗外的哥特城市与蝙蝠、红绒桌布书桌、三枝烛台与壁烛、古堡油画、哥特挂钟、信件格架、盆栽、矮书柜上的黑猫。桌面物件逐个以原生像素绘制。女伯爵与主编肖像来自 `src/art/portraitData.ts`（由参考像素图无损转换，1 图像像素 = 1 原生像素）。
- 藏书阁：纵深阅览厅；侧窗、拱门书库、高书架、取书梯、长阅览桌和新书展台。
- 办公室：四个部门工位（挂旗与图标区分职责，未启用的盖着防尘布）、茶水柜、公告板，地毯中央是徽标。
- 作者室：签约画像与会谈圆桌；画像有发型、眼镜和铭牌，空位是暗色剪影。
- 书房：扶手椅、书架、壁炉（下移，为壁炉上方的两幅肖像留位）。
- 档案室：卡片抽屉墙、奖杯陈列柜、账本桌。

业务面板和存档格式沿用原有系统。

## 源码入口

| 文件 | 职责 |
| --- | --- |
| `src/art/pixels.ts` | 色板、整数栅格绘制、固定种子的纹理、有限明暗色阶 |
| `src/art/rooms.ts` | 六个房间的构图、家具、肖像、壁炉火焰和动画 |
| `src/art/weather.ts` | 窗外天气（雨、雪、雾、风、雷）、玻璃水滴折射、闪电 |
| `src/art/covers.ts` `handCovers.ts` | 书封：手绘封面的无损数据，以及按书名和题材生成的其余封面 |
| `src/art/layout.ts` | 按设备像素比计算整数倍显示尺寸 |
| `src/core/weather.ts` | 按游戏日历决定天气（每 6 个游戏日一次，季节加权，可复现） |
| `src/audio/ambience.ts` `mix.ts` | Web Audio 合成环境音；`sceneMix` 决定各层音量 |
| `src/components/scene/PixelRoomCanvas.tsx` | 静态图层缓存、Canvas 输出、动画与音频生命周期 |
| `src/components/scene/PixelStage.tsx` | 让画面和点击区域使用同一坐标空间，并读取天气 |

桌面采用整数物理像素倍数填满并裁切，手机按宽度选择整数倍。Canvas 关闭平滑，CSS 使用 `image-rendering: pixelated`。文字和面板使用正常 DOM。

## 物件轮廓与点击

绘制时每个可点物件把像素登记到 `tags`（`OBJECTS` 列表，`tagged(p, key, draw)`）。`PixelStage` 用它做命中判定：悬停时沿物件实际轮廓描金边（`src/art/outline.ts`），点击物件任何像素即触发带同名 `data-object` 的按钮。矩形按钮保留给键盘和读屏。每帧动画的物件（来稿、打字机、猫）在静态层以只登记不上色的方式占位。

## 动态与天气

有窗的房间（主编室、办公室、书房、藏书阁）每秒最多绘制十帧；作者室和档案室是静态的。隐藏房间停止绘制，后台页面和系统减少动态偏好停止动画（此时显示天气的一帧静态）。

天气只影响窗内像素，窗框最后重绘，天气永远在窗框后面。雨滴用缓存的静态帧做采样，所以是“折射”窗后的城市，而不是折射雨本身。雷暴闪光时，房间整体提亮一档，窗内用第六档。

## 环境音

不使用音频文件。首次点击或按键后才创建 AudioContext；页面隐藏时挂起。各层由 `sceneMix(天气, 房间, 是否工作)` 决定：雨、风、雪雾的低噪、蟋蟀（晴夜）、炉火（书房）、打字机（主编室工作时）。没有窗的房间只听到隔墙的低频，雷声总是最后留下的。设置保存在 `localStorage`（键 `idleditor.audio`）。

## 修改和预览

1. 修改 `rooms.ts` 中对应房间或共享家具函数。
2. 配色从 `INK` 选择，纹理使用固定 `noise`，避免逐帧随机闪烁。
3. `npm run art:render` 导出六个房间和 `weather.png`（六种天气）；`node scripts/render-covers.mjs 12` 导出封面样张（加 `- x styles` 看三种取向）。
4. 检查 `.dream-loop/procedural/` 下的最近邻 PNG，再在游戏中检查热区和面板。导出图不会被游戏加载。

## 验证和边界

- 全量测试通过，含绘制、状态变化、像素缩放、动画生命周期、封面、天气和音频混音。
- 音频在真实浏览器中验证：首次点击后建立音频图，暴雨/雷声/炉火/隔墙的电平符合预期，开关有效。
- 其他房间完整交互、最新手机触控布局尚未逐项复核。
- 构建仍提示旧字体回退文件缺失和 JS 包较大。
