# 永夜出版社 · 代码绘制场景

更新：2026-09-29。

## 当前实现

六个房间均由 TypeScript 在 **480×270** 的整数像素网格上直接绘制。房间、家具、书籍和动态物件使用矩形、整数直线、多边形和椭圆；使用固定基础色板及五档明暗色阶。场景不再依赖 PNG 背景。

- 主编室：正面大窗、编辑桌、打字机、来稿、日记、红茶与可获得的黑猫。
- 藏书阁：独立的纵深阅览厅构图；侧窗、远处拱门书库、前景高书架、取书梯、纵向长阅览桌和新书展台。
- 办公室：四个部门工位、茶水柜与设置手册。
- 作者室：签约画像与会谈圆桌。
- 书房：扶手椅、书架、壁炉。
- 档案室：档案抽屉、账本与奖杯。

业务面板和存档格式沿用原有系统。书籍封面仍使用原有内容资源。

## 源码入口

| 文件 | 职责 |
| --- | --- |
| `src/art/pixels.ts` | 色板、整数栅格绘制、固定种子的纹理、有限明暗色阶 |
| `src/art/rooms.ts` | 六个房间的构图、家具、状态映射和动画 |
| `src/art/layout.ts` | 按设备像素比计算整数倍显示尺寸 |
| `src/components/scene/PixelRoomCanvas.tsx` | 静态图层缓存、Canvas 输出、动画生命周期 |
| `src/components/scene/PixelStage.tsx` | 让画面和点击区域使用同一坐标空间 |
| `src/components/scene/rooms/` | 房间入口和原有业务面板 |

桌面采用整数物理像素倍数填满并裁切，手机按宽度选择整数倍；极窄低 DPI 屏幕最少显示一倍。Canvas 关闭平滑，CSS 使用 `image-rendering: pixelated`。文字和面板使用正常 DOM，以保持可读和可操作。

每次相关状态改变时重建静态图层。主编室的雨、蒸汽、打字机与猫，以及书房火焰每秒最多绘制十帧。静态房间无需持续绘制；隐藏房间停止绘制，后台页面和系统减少动态偏好停止动画。

## 游戏状态与画面

- 待审稿件改变纸堆高度，最多显示十层。
- 工作中的稿件启动打字机动作。
- 获得黑猫后才绘制黑猫。
- 出版数量改变藏书阁新书展台上的书；有限陈列空间之外的数量仍由标签和面板显示。
- 签约作者填充画像；启用部门改变办公室工位。

主编室物件边界集中在 `DESK_OBJECTS`。其他房间的点击区域位于对应 React 房间组件中。调整构图后同步检查热区。

## 修改和预览

1. 修改 `rooms.ts` 中对应房间或共享家具函数；藏书阁使用独立的 `libraryRoom`。
2. 配色从 `INK` 选择，纹理使用固定 `noise`，避免逐帧随机闪烁。
3. 运行 `npm run art:render`，调用正式绘制器输出六个房间及空主编室。
4. 检查 `.dream-loop/procedural/` 下的三倍最近邻 PNG，再在游戏中检查热区和面板。导出图用于检查场景，不会被游戏反向加载。

此前 AI 底稿和采样 PNG 已停用。既有历史场景文件保留，但六个房间不加载它们，PWA 也排除了场景 PNG 的预缓存。历史提示词见 `pixel-workbench-prompts.md`。

## 参考

参考 [Lofi Cities](https://loficities.com/) 的低分辨率绘制、有限色板、图层缓存与轻微环境动态。2026-09-28 核查其公开脚本，原生场景为 480×270。本站场景代码独立编写。
