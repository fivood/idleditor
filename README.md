# [永夜出版社](https://idleditor.fivood.com) · Idle Editor

> 一个活了 217 年的吸血鬼编辑的日常。审稿、出版、养猫、熬死伯爵——挂机为辅，经营为主。

你是一位不朽的吸血鬼。永夜出版社（你的同类创办）聘请你来当编辑，他们觉得反正你闲着也是闲着。出版社的茶水间里没有镜子、红茶配方可疑、实习生被一代又一代换掉，但你从来没变过。

## 世界观

世界本身是「正常」的——有白天有黑夜，普通人类社会照常运转，大多数人并不知道超自然生物真实存在。在这之外，存在一个低调的「**夜行社群**」：吸血鬼、狼人、女巫、食尸鬼、亡灵等与人类社会平行共存，自有机构、酒馆、出版社、银行。

**永夜出版社**坐落在夜行社群的某条街上。大老板伯爵是吸血鬼。玩家也是吸血鬼，担任主编，**只在日落到日出之间工作**。多数编辑同事也是吸血鬼，但出版社也雇佣可耐光的物种（精灵、半魔裔、日间女巫）和人类知情者负责白班事务（采购、印刷协调、与日间作者沟通）。

世界观直接驱动题材语义反转——你以为的"科幻"在吸血鬼编辑眼里是**「日光幻想」**（关于阳光、白班世界、人类日常的奇想推演——他们自己永远体验不到）；"推理"是**「凡间悬案」**（人类视角的离奇事件，对夜行读者就像异域奇谈）；"悬疑"是**「银器恐怖」**（涉及银/十字架/阳光这些夜行禁忌元素）；"社科"是**「真实研究」**（关于夜行社群的纪实）；"轻小说"是**「少年血宫」**（年轻吸血鬼/狼人的转生爽文）。

办公室可开关「**凡间专栏**」——决定是否接受人类作家投稿。开启时约 30% 概率收到现实戏仿稿（《四体》《祈尔摩斯》），关闭则只产出夜行族原生题材（《吸血鬼家族的衰落》《嚎叫分级守则》《转生成吸血鬼但只想睡觉》等 165+ 本土标题）。

### 未来计划：昼夜系统 + 梦境创作

时间和昼夜系统在路线图上：白天玩家必须睡觉，而**入梦时可以创作自己的作品出版**——一个独立于夜间审稿之外的挂机机制。世界观为此保持开放：夜行族裔只是这个世界的一个亚群，不是全部。

## 空间化导航

游戏界面是一栋可走访的出版社建筑，不是 6 个抽象 Tab。**每个标签是一间 45° 等距像素房间**，你点击场景内的物件弹出操作面板：

| 房间 | 进门看到什么 |
|------|------------|
| **桌面** | 你的私人办公室。砖墙 + 哥特窗 + 木桌 + 油灯 + 稿件堆 + 蜷睡黑猫。点稿件堆开投稿池，点桌面中央开编辑流水线，点油灯看出版日志 |
| **办公室** | 开放式工位区（中心枢纽）。4 部门工位一字排开 + 茶水间（血浆温热柜+红茶罐）+ 中央"永夜出版社"地毯。点部门升级，点中央徽标改设置 |
| **书架** | 永夜藏书阁。三面顶天书墙 + 染色玻璃拱顶窗（红/金/绿/蓝 4 扇）+ 月光柱 + 旋转梯子 + 绿罩台灯阅读桌。书的密度跟随你的出版量变化 |
| **作者** | 作家接待室。4 幅作家肖像墙（已签作家=铜框金光/未签=灰）+ 椭圆圆桌（茶壶冒蒸汽+红茶+杯）+ 4 把高背椅 + 红毯 + 落地烛台 |
| **书房** | 你的私人阅读厅。雨窗 + 中央壁炉（跳动的火焰 + 暖光晕）+ 高背皮椅 + 落地灯 + 个人书架 + 旧波斯地毯 |
| **档案** | 档案室。5×5=25 个抽屉墙（标签会随出版数变铜色"已填"）+ 中央账本桌 + 蜡封卷轴墙挂 + 顶部吊灯 |

**导航方式：**
- 鼠标 hover 场景物件 → 黄色虚线框 + 标签提示
- 左下角桌沿浮 6 房间速跳 **minimap**（永久可见）
- 房间两侧有"通往走廊"门
- 桌面端 `1-6` 数字键直接切换、`Esc` 回办公室枢纽
- 移动端保留底部 Tab 栏（屏幕小不便 hover）

## 像素艺术风格

全游戏统一像素美学：

- **顶栏木牌**：暗色木质渐变 + 铜色文字 + 每个货币是独立铜框木牌（图标 + 数字）
- **25 个像素图标**（统一 16×16，`shape-rendering: crispEdges`）替换全部 emoji
- **像素进度条**：方块拼成 + 硬阴影 + 顶部高光 + `steps(20)` 跳格动画
- **稿件卡片**：做旧米黄纸张材质 + 题材色带 + 随机回形针/咖啡渍 + 整齐对齐
- **6 种弹窗艺术 variant**：纸张 / 木质收件托盘（带铆钉）/ 铁质流水线带（带螺丝钉）/ 翻开的羊皮日记 / 上下木轴卷轴 / 软木公告板
- **空状态插画**：投稿池空时显示"待审"铜牌托盘+灰尘+孤零零的笔；流水线空时显示静止的传送带+齿轮+暂停灯

## 核心玩法

稿件不断涌入投稿池。每份稿件按类型分色 + 做旧纸张样式——**你的工作是判断：审稿、退稿还是搁置？**

- 新来稿默认**折叠遮盖**，点「翻阅」触发翻页进度条动画
- 稿件卡片显示**初筛印象**标签（初筛存疑→潜力之作四档）
- 退掉烂稿赚修点和声望。退掉好书扣声望，签约作者退稿减好感，有概率被**竞争出版社永久挖走**
- 审稿后进入编辑流水线：审稿 → 编辑(可选精校) → 校对 → 封面查看 → 出版
- 投稿池上限 **7 份**，闲置超 10 分钟的稿子自动消失
- **征稿系统**：公开征稿（免费）/ 定向约稿（30 RP，品质+10）/ 加急征稿（100 版税）三选一

## 作者系统

**17 种人格**——退休教授、地下室科幻宅、前情报官员、社会学博士、焦虑新人、隐居拉美作家、北欧推理女王、美国畅销流水线、日本轻小说宅、考据派历史作家、奇幻史诗执笔、法国文学隐者、印度史诗圣者、俄式沉重长卷、韩国网文女王、尼日利亚魔幻写实、澳洲内陆哥特。

- **生涯上限**：高产型（韩国网文女王 >40 本）→ 一书封神型（印度史诗圣者 1-3 本），封笔后不再投稿
- 三段晋升（签约→知名→传奇）+ 隐藏好感度 + 忠诚标记
- 互动：请吃饭/寄样书/写回信（120s 共用冷却）
- **解约**功能——弹窗确认："婚姻都有破裂的可能…"

## 猫生系统

收养猫为**随机决策事件**（窗外来了一只猫）。取名（最多 6 字）、摸猫（+3 好感，60s 冷却）、逐年变老。好感 ≥ 80 且猫龄 ≥ 5 时可**消耗 1 铜像赐予永生**。未永生且好感 < 50 的猫在 10 岁后可能离世。

## 图书与封面

**400+ 个标题** = 232 个现实戏仿（《四体》《祈尔摩斯》《修道院物管疑云》等）+ 165 个永夜原生（《银器走私集团》《转生成吸血鬼但只想睡觉》等）。95+ 篇手写戏仿简介，每本书有原著剧情戏仿描述。

## 天赋树

编辑等级提升解锁天赋。**5 层 15 个天赋，每层三选一，永久生效，纪元保留。**

## 纪元系统（原"转生"）

满足条件后顶栏出现「**纪元**」按钮（带棺木 + 十字像素图标 + 铜色发光）。铸造铜像重置进度，保留永久加成。**第 1/3/5/7 次纪元触发伯爵剧情场景**，第 5 次可选伯爵性别，第 10 次触发结局。可选三条纪元路线：学者 / 商人 / 名流。

## 部门与运营

4 个部门（编辑/设计/市场/版权），**升级成本随等级递增**（×1.5），进度条实时显示。设计部在封面阶段加品质，版权部每 tick 产出声望。

**审稿门槛滑块**：设品质下限，低于门槛的稿件全自动出版。**自动化特权**（自动审稿/自动出版/自动退稿）可在办公室开关。**题材黑名单**：把不想要的题材加入后配合自动退稿，会立刻被退回。

## 书店与事件链

- **书店经营系统**：投资建立线下书店（最多三家）。摆放货架、安排旗下畅销书签售获得数倍销量加成、装修升级店铺
- **事件链系统**：环环相扣的连环事件（神秘连载小说、午夜钟声等），连续抉择导向不同结局与收益

## 书房（内置阅读器）

上传 `.txt` / `.md` / `.epub`。EPUB 自动解析章节。阅读进度每 5 秒自动保存，手动书签。切换标签页不丢状态。

## 数据档案

档案房间展示多维度的经济走向图表、各题材图书销量占比、编辑生涯回顾。**抽屉墙的标签会随出版数逐步变铜色"已填"**，可视化你的成长。

## 云存档安全

云存档使用 **SHA-256 加盐哈希**存储密码（不是明文）。**连续 5 次错误密码锁定 15 分钟**（按 IP + 存档码维度）。所有 AI 接口加入速率限制和输入净化，防止 prompt 注入与服务滥用。

## 技术栈

React 19 + TypeScript + Vite + Tailwind v4 · Zustand (Slice Pattern + Immer) · Dexie.js (IndexedDB) · Cloudflare Pages + Functions + KV · 全部场景与图标用 inline SVG（gzip 后总 < 10KB）
