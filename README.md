# [永夜出版社](https://idleditor.fivood.com) · Idle Editor

> 一个活了 217 年的吸血鬼编辑的日常。审稿、出版、养猫、熬死伯爵——挂机为辅，经营为主。

你是一位不朽的吸血鬼。永夜出版社（你的同类创办）聘请你来当编辑，他们觉得反正你闲着也是闲着。出版社的茶水间里没有镜子、红茶配方可疑、实习生被一代又一代换掉，但你从来没变过。

## 永夜世界

游戏发生在一个夜晚永远不会结束的世界。主要居民是吸血鬼、狼人、女巫、食尸鬼，**人类只占人口约 12%，是少数族裔**，多数在白班机构（银行、邮局、市政厅）任职。银器、十字架、镜子都是敏感物品。出版业的咖啡机是"血浆温热柜"，茶水间的红茶颜色可疑。重大节日包括血协议纪念日、月圆狂欢、永夜文学奖颁奖夜。

世界观直接驱动题材语义反转——你以为的"科幻"在永夜里叫**「日光幻想」**（关于人类、阳光、白班世界的奇想推演）；"推理"是**「凡间悬案」**（人类视角的离奇事件汇编）；"悬疑"是**「银器恐怖」**；"社科"是**「真实研究」**（关于永夜社会的纪实）；"轻小说"是**「少年血宫」**（年轻吸血鬼/狼人的转生爽文）。

办公室可开关「**凡间专栏**」——决定是否接受人类作家投稿。开启时约 30% 概率收到现实戏仿稿（《四体》《祈尔摩斯》），关闭则只产出永夜原生题材（《吸血鬼的历史》《嚎叫分级制度》《转生成吸血鬼但只想睡觉》等 165+ 本土标题）。

## 像素艺术风格

- **6 种弹窗艺术 variant**：纸张 / 木质收件托盘（带铆钉）/ 铁质流水线带（带螺丝钉）/ 翻开的羊皮日记 / 上下木轴卷轴 / 软木公告板

## 核心玩法

稿件不断涌入投稿池。每份稿件按类型分色 + 做旧纸张样式——**你的工作是判断：审稿、退稿还是搁置？**

- 新来稿默认**折叠遮盖**，点「翻阅」触发翻页进度条动画
- 稿件卡片显示**初筛印象**标签（初筛存疑→潜力之作四档）
- 退掉烂稿赚修点和声望。退掉好书扣声望，签约作者退稿减好感，有概率被**竞争出版社永久挖走**
- 审稿后进入编辑流水线：审稿 → 编辑(可选精校) → 校对 → 封面查看 → 出版
- 投稿池上限 **7 份**，闲置超 10 分钟的稿子自动消失
- **征稿系统**：公开征稿（免费）/ 定向约稿（30 RP，品质+10）/ 加急征稿（100 版税）三选一

## 部门与运营

4 个部门（编辑/设计/市场/版权），**升级成本随等级递增**（×1.5），进度条实时显示。设计部在封面阶段加品质，版权部每 tick 产出声望。

## 数据档案

档案房间展示多维度的经济走向图表、各题材图书销量占比、编辑生涯回顾。**抽屉墙的标签会随出版数逐步变铜色"已填"**，可视化你的成长。

## 云存档安全

云存档使用 **SHA-256 加盐哈希**存储密码（不是明文）。**连续 5 次错误密码锁定 15 分钟**（按 IP + 存档码维度）。所有 AI 接口加入速率限制和输入净化，防止 prompt 注入与服务滥用。
